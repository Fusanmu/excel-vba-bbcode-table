# Excel to BBCode Table

将 Excel 选区转换为适用于 Keylol 等 Discuz 论坛的 BBCode 表格，并复制到剪贴板。

## 功能

- 保留合并单元格、文本换行、对齐、字号、粗体、斜体、下划线和字体颜色。
- 按 Excel 实际列宽计算 BBCode 列宽。
- 支持普通填充色和条件格式产生的显示填充色。
- 对整行主色使用 `[tr=颜色]`，减少冗余 BBCode。
- 对单独着色的单元格生成 100% 宽度的嵌套表格，绕过 Keylol 不支持单独设置 `td` 背景色的限制。
- 正确输出 Keylol/Discuz 的合并单元格参数，并使用真实换行代替不受支持的 `[br]`。
- 默认保留单元格内的 `[sframe]` 等可信 BBCode，使其能够在论坛中正常解析。

单个黄色单元格的核心输出形式如下：

```text
[td=1,1,25%][table=100%,#FFFF00][tr][td]内容[/td][/tr][/table][/td]
```

只有当某种填充色占一行单元格的严格多数时，才会把它设为行背景。因此，一行中孤立的填色单元格不会被错误地扩展为整行背景。

## 使用

1. 在 Excel 中按 `Alt+F11` 打开 VBA 编辑器。
2. 导入 `excel_to_bbcode_table.bas`，或将代码粘贴到标准模块。
3. 回到 Excel，选中需要转换的区域。
4. 运行宏 `CopySelectionToBBCodeTable`。
5. 将剪贴板内容粘贴到论坛编辑器并预览。

如需从其他宏中直接取得字符串，可以调用 `RangeToBBCodeTable(某个区域)`，该函数不会操作剪贴板或显示提示框。

文件顶部的常量可以调整表格宽度、默认背景色、行主色、嵌套表格和条件格式读取行为。

`ESCAPE_TEXT_BRACKETS` 默认为 `False`，适合在 Excel 中主动填写 `[sframe]` 等论坛标签。不要转换来自不可信来源的 BBCode；如果只希望输出纯文本，请将该常量设为 `True`。

如果导入后中文注释显示乱码，请直接在 VBA 编辑器中新建标准模块并粘贴源码；这不影响宏的功能。

## 注意

嵌套表格是否带额外边框或内边距由论坛主题决定。建议先用小选区预览；如果论坛样式发生变化，可以将 `USE_NESTED_CELL_TABLE` 设为 `False` 暂时关闭单元格背景模拟。
